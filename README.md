# Экранный переводчик (ScreenTranslator)

Фоновое приложение для Windows 10 (2004+) и Windows 11: выделите область экрана —
приложение распознает текст (встроенный OCR Windows, офлайн) и покажет перевод в окне
рядом с областью. В том же окне можно написать ответ на родном языке и перевести его
на язык собеседника.

## Возможности

| Функция | Как пользоваться |
|---|---|
| Перевод области | `Ctrl+Shift+T` → выделить мышью область (Esc / правая кнопка — отмена) |
| Повтор последней области | `Ctrl+Shift+R` — та же область без выделения (сохраняется между запусками) |
| Офлайн-перевод | Встроенные нейросетевые модели Opus-MT и NLLB-200 (ONNX): без интернета, сервера и Docker |
| Перевод онлайн | Google Переводчик через бесплатный адрес без ключа; нужен интернет; таймаут 10 с |
| LibreTranslate | Свой или публичный сервер (необязательно, включается в настройках) |
| Выбор сервиса | Прямо в окне перевода, рядом с языком перевода; выбор сохраняется |
| Размер окна | Окно перевода растягивается за любой край или угол, размер запоминается; двойной щелчок по заголовку — обычный размер |
| Перевод в браузере | Кнопки «Google» и «Яндекс» в окне перевода — для распознанного текста и для ответа |
| DeepSeek | Кнопка «DeepSeek» открывает chat.deepseek.com и вставляет картинку с текстом. **Нужно быть авторизованным в DeepSeek** |
| Быстрый ответ | Поле «Ваш ответ» → Enter; перевод копируется в буфер (настраивается) |
| История | Последние 50 переводов, поиск, копирование, «Открыть» |
| Тема | Светлая/тёмная по системной настройке; скругления Windows 11 |

## Сборка

### 1. Инструменты

* Windows 10 версии 2004 (сборка 19041) или новее, либо Windows 11.
* [.NET SDK 8](https://dotnet.microsoft.com/download/dotnet/8.0) или новее (подходит и .NET 9/10 SDK):
  ```
  winget install Microsoft.DotNet.SDK.8
  ```
* (необязательно) Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений .NET»
  или VS Code с расширением C# Dev Kit.

Проверка: `dotnet --list-sdks`.

### 2. Сборка и запуск для разработки

```
cd ScreenTranslator
dotnet build
dotnet run
```

### 3. Один exe-файл (self-contained, .NET устанавливать не нужно)

```
dotnet publish -c Release -p:PublishProfile=SingleFile
```

Результат: `bin\publish\ScreenTranslator.exe` (~75 МБ). Его можно скопировать на любой
компьютер с Windows 10 2004+ / Windows 11 (x64) и запустить.

То же самое без профиля:

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o bin\publish
```

### 4. Установщик (рекомендуется для пользователей)

Нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php): `winget install JRSoftware.InnoSetup`.

```
powershell -ExecutionPolicy Bypass -File Installer\build-installer.ps1
```

Результат: `bin\installer\ScreenTranslatorSetup.exe`. Установщик не требует прав администратора, ставит
приложение в `%LocalAppData%\Programs\ScreenTranslator`, создаёт ярлык, по желанию включает автозапуск
и предлагает выбрать языки. После установки приложение само включает офлайн-перевод и скачивает
выбранные языковые модели (окно с прогрессом).

## Офлайн-перевод (по умолчанию)

Перевод выполняется прямо в приложении моделями [Opus-MT](https://github.com/Helsinki-NLP/Opus-MT)
(Helsinki-NLP) в формате ONNX ([Xenova на Hugging Face](https://huggingface.co/Xenova)) через ONNX Runtime.

* Модели ставятся в «Настройки → Перевод в окне → Встроенный офлайн-переводчик» (кнопка «Установить
  Русский ↔ Английский» или по одной), хранятся в `%LocalAppData%\ScreenTranslator\models`, ~110 МБ на направление.
* Пары без прямой модели (например, немецкий → русский) переводятся через английский.
* **NLLB-200** (Meta, 600 млн параметров, ~870 МБ) — одна модель для всех языков приложения, переводит напрямую
  без английского и лучше понимает обычный текст, но медленнее (0,5–3 с на фразу) и во время перевода занимает
  до 3 ГБ памяти. Включается флажком «Переводить моделью NLLB-200» в настройках; если для пары нет моделей
  Opus-MT, NLLB используется автоматически.
* Модель загружается в память при первом переводе (~0,5 с) и выгружается после 3 минут простоя.
* Перевод — лучевым поиском (4 луча), около 0,3–1,5 с на предложение.
* Самопроверка без интерфейса: `ScreenTranslator.exe --selftest` → `%AppData%\ScreenTranslator\selftest.txt`.

## Перевод онлайн

Пункт «Перевод онлайн» в окне перевода (или в «Настройки → Перевод в окне») переводит текст Google Переводчиком
через бесплатный адрес `translate.googleapis.com` (тот же, что используют расширения браузеров). Ключ и регистрация
не нужны, язык исходного текста Google определяет сам. Адрес неофициальный: при очень частых запросах Google может
временно ограничить доступ — тогда приложение пробует запасной адрес, а если и он недоступен, предлагает перевести
офлайн. Распознанный текст при этом отправляется в Google.

## Перевод через DeepSeek

**Важно: нужно быть авторизованным в DeepSeek** — заранее войдите в свой аккаунт на <https://chat.deepseek.com>
в браузере, который выбран в настройках переводчика (или в браузере по умолчанию). Без входа сайт покажет
страницу авторизации и вставка не сработает.

Кнопка «DeepSeek» под распознанным текстом:

1. копирует снимок выделенной области в буфер обмена и открывает chat.deepseek.com в новой вкладке;
2. когда вкладка DeepSeek становится активной, вставляет в поле сообщения просьбу перевести на выбранный язык
   и картинку (как Ctrl+V). Вставка выполняется, только если активно именно окно DeepSeek;
3. остаётся проверить и нажать Enter. Если поле осталось пустым — нажмите в нём Ctrl+V: картинка остаётся в буфере.

API и ключ не нужны — используется ваш аккаунт на сайте. Для записей из истории (картинки нет) вставляется текст.
Картинка отправляется на сервер DeepSeek.

## LibreTranslate (необязательно)

Укажите адрес сервера в «Настройки → Перевод в окне». Публичный `https://libretranslate.com` требует ключ;
свой сервер: `docker run -p 5000:5000 libretranslate/libretranslate` → адрес `http://localhost:5000`.
В списке сервисов окна перевода LibreTranslate появляется, только пока он выбран в настройках.

Ключи хранятся в `settings.json` в зашифрованном виде (Windows DPAPI, привязка к учётной записи).

## Языки распознавания (OCR)

OCR работает для языков, установленных в Windows. Добавить язык:
«Параметры» → «Время и язык» → «Язык и регион» → «Добавить язык», или в PowerShell от администратора:

```
Get-WindowsCapability -Online | Where-Object Name -like 'Language.OCR*'
Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"
```

## Где хранятся данные

`%AppData%\ScreenTranslator\`:
* `settings.json` — настройки (включая последнюю область для повтора);
* `history.db` — история (SQLite);
* `error.log` — журнал ошибок.

Снимки выделенной области **нигде не сохраняются**: распознавание идёт в памяти, в истории хранится только текст,
в настройках — только координаты последней области. Для кнопки «DeepSeek» снимок временно кладётся в буфер обмена
с пометкой «не сохранять в журнал буфера обмена (Win+V) и не синхронизировать» и через 2 минуты убирается оттуда,
если за это время ничего другого не копировали.
